# 2shakilrafi.github.io

Personal website for Shakil A. Rafi, Ph.D. Built with [Quarto](https://quarto.org/) and deployed from the rendered `docs/` directory on GitHub Pages.

## Local development

```bash
/Applications/RStudio.app/Contents/Resources/app/quarto/bin/quarto preview
```

## Render for deployment

```bash
/Applications/RStudio.app/Contents/Resources/app/quarto/bin/quarto render
```

Commit both the source files and the generated `docs/` output. The site is designed to work without third-party JavaScript, analytics, or externally hosted fonts.
